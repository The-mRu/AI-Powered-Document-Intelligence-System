# Walkthrough recording

The assignment requires a recorded walkthrough. No recording is stored in this repository.

To produce one, run `docker compose up --build`, open `http://localhost:3000`, and demonstrate:

1. Uploading multiple PDF/image/spreadsheet files.
2. Processing progress and failed-file handling.
3. Extracted fields, evidence, OCR text, validation issues, and review status.
4. Editing, approving, and reprocessing a document.
5. Keyword and semantic search.

Store the recording externally according to the submission channel and add its URL to the final submission. Do not add credentials to the recording.
